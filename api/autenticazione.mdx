Ogni richiesta deve includere una chiave API nell'header `Authorization` con schema `Bearer`. Le richieste senza chiave valida ricevono `401`.

```bash
curl "https://app.gestionesala.com/api/v1/guests/lookup?phone=3391112233" \
  -H "Authorization: Bearer $GS_KEY"
```

## Header

| Header | Valore | Obbligatorio |
| --- | --- | --- |
| `Authorization` | `Bearer gsk_<64 caratteri esadecimali>` | Sì, su tutti gli endpoint |
| `Content-Type` | `application/json` | Sì, sulle richieste con body |
| `Idempotency-Key` | Stringa scelta dal client | No. Solo su `POST /reservations` e `POST /waitlist`. Vedi [Idempotenza](/api/idempotenza) |

## Permessi

Una chiave API identifica un'organizzazione e un membro di quell'organizzazione. Ogni richiesta ha gli stessi permessi e la stessa visibilità sui locali di quel membro nell'app.

- Un locale non visibile al membro restituisce `404 not_found`.
- Un'operazione non consentita al membro restituisce `403 forbidden`.

## Creare una chiave

<Steps>
  <Step title="Apri Collegamenti">
    Nell'app apri **Impostazioni → Collegamenti**, sezione **Agente vocale**. Serve il permesso sui collegamenti.
  </Step>
  <Step title="Assegna un nome">
    Inserisci un nome che identifichi il sistema che userà la chiave, ad esempio `Agente telefono sala`.
  </Step>
  <Step title="Crea la chiave">
    Premi **Crea una chiave**. La chiave viene mostrata una sola volta.
  </Step>
</Steps>

<Warning>
  Il server conserva solo l'hash SHA-256 della chiave. Una chiave persa non è recuperabile: creane una nuova e revoca quella precedente.
</Warning>

## Revocare una chiave

Nella stessa sezione, apri il menu della chiave e scegli **Revoca**. La revoca ha effetto immediato: le richieste successive con quella chiave ricevono `401 api_key_revoked`.

## Errori di autenticazione

| Status | `code` | Causa |
| --- | --- | --- |
| `401` | `unauthenticated` | Header `Authorization` assente o senza schema `Bearer` |
| `401` | `api_key_invalid` | Chiave sconosciuta o malformata |
| `401` | `api_key_revoked` | Chiave revocata |

```json
{ "error": { "code": "unauthenticated", "message": "serve una chiave API", "details": {} } }
```

## Conservazione della chiave

Non inserire la chiave nel codice sorgente o in un repository. Passala al sistema chiamante tramite variabile d'ambiente, ad esempio `GESTIONESALA_API_KEY`.
